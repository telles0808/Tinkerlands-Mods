# 🕒 RealClock Mod (v1.0)

Responsive real-world clock HUD for Tinkerlands.

## ✨ Features
- Displays the computer's local time in 24-hour `HH:MM` format.
- Does not require the Clock accessory to be equipped.
- Uses the native embedded pixel font with high-visibility yellow text.
- Draws after the native HUD so the minimap cannot cover it.
- Scales and stays anchored to the top-right corner across resolutions.

## 📥 Installation
1. Place `RealClock.mod` inside `C:\Program Files (x86)\Steam\steamapps\common\Tinkerlands\mods\`.
2. Clear `%LOCALAPPDATA%\Tinkerlands\temp` if upgrading from an older version.
3. Launch Tinkerlands!
