# 📡 NPC Radar Mod (v1.3)

High-performance NPC radar and tracking HUD for Tinkerlands.

## ✨ Features
- Real-time off-screen directional indicators with exact distances in meters.
- Native character portraits for all 38 NPCs via internal `npcID` resolution.
- Responsive HUD Sonar toggle button.
- Performance-optimized tick system (zero stuttering).

## 📥 Installation
1. Place `Radar.mod` inside `C:\Program Files (x86)\Steam\steamapps\common\Tinkerlands\mods\`.
2. Clear `%LOCALAPPDATA%\Tinkerlands\temp` if upgrading from an older version.
3. Launch Tinkerlands!
