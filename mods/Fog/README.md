# 🌫️ Fog of War Translucency Mod

Custom minimap rendering hook for Tinkerlands.

## ✨ Features
- 95% translucent fog of war layer.
- Retains terrain and structure visibility after exploration.
- Safe hook into native GameMaker surface rendering pipeline.

## 📥 Installation
1. Place `Fog.mod` inside `C:\Program Files (x86)\Steam\steamapps\common\Tinkerlands\mods\`.
2. Clear `%LOCALAPPDATA%\Tinkerlands\temp` if needed.
3. Launch Tinkerlands!
